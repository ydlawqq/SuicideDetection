# Дообучение моделей для классификации суицидальных наклонностей

## Датасет
В качестве обучающего набора данных будет использоваться [Данный датасет](https://huggingface.co/datasets/astromis/presuicidal_signals)

### Подготовка и анализ

Смотрим на среднюю длину всех текстов, очищаем текст, превращаем эмоджи в слова (вместо 😭 - "слезы рекой"), удалять нельзя, эмоджи важны, показывают отображение эмоций.
Лемматизируем, для RNN создаем и обучаем токенизатор, для энкодера будем использовать готовый. 
Создаем класс для датасета, токенизация будет происходить в конструкторе, и выполнится при первом создании датасета (токенизировать на лету в getitem - долго).

В результате готовый датасет должен иметь колонки: `['input_ids', 'attention_mask', 'labels']`
 
## Модели


#### BiLSTM: Эмбеддинг слой, рекуррентный слой, дропаут, линейный слой. 

Построим токенизатор для RNN, создадим саму модель, создадим слой эмбеддингов, определим их размер, размер скрытого состояния, не забудем упаковать тензор с помощью `pack_padded_sequence`, что бы `<PAD>` токены не участвовали в обучении. Создаем адаптер - выходом будут логиты в размерности `[batch_size,]`.

#### Encoder aka *BERT*: тут ничего необычного, дообучение отдельных слоев мало чем помогает, поэтому делаем полный SFT.

Загружаем модель с головой в один логит, токенизатор, создаем адаптер. Обязательно веса в float32, иначе логиты становятся NaN.


## Выбор метрик

Очевидно, что в данной задаче будем брать recall как целевую метрику, при приемлемом f1, полнота классификаций очень важна.
Помимо них на валидации будем смотреть на roc-auc, loss. Выбираем лучшую модель по loss на валидации. Строим PR кривую и по ней подбираем трешхолд. (Не самый лучший вариант на данный момент, позже переделаю и отредактирую раздел.) 


## Выбор Loss

Были протестированны различные подходы, взвешивание ошибки на положительном классе с `BCE`, оверсемплинг с обычным `BCE`, без оверсемплинга и взвешивания, и даже `FocalLOSS`.
Лучше всего себя показало взвешивание, с весом, обратно пропорциональным доле класса.
