# Данный ноутбук представляет собой тестирование двух разных архитектур моделей
1. Обучение RNN с нуля.
2. Дообучение разных слоев небольших Encoder моделей. 



## Датасет
В качестве обучающего набора данных будет использоваться [Данный датасет](https://huggingface.co/datasets/astromis/presuicidal_signals)

### Подготовка и анализ

Смотрим на среднюю длину всех текстов, очищаем текст, превращаем эмоджи в слова (вместо 😭 - "слезы рекой"), удалять нельзя, эмоджи важны, показывают отображение эмоций.
Лемматизируем, для RNN создаем и обучаем токенизатор, для энкодера будем использовать готовый. 
Создаем класс для датасета, токенизация будет происходить в конструкторе, и выполнится при первом создании датасета (токенизировать на лету в getitem - долго).

В резьтате готовый датасет должен иметь колонки: ['input_ids', 'attention_mask', 'labels']
 
## Архитектуры моделей

BiLSTM: Эмбеддинг слой, рекуррентный слой, дропаут, линейный слой. 

Encoder: Тестировал несколько моделей, все из bert семейства, дообученные на классифицаию тональности/сентиментальности (наиболее близкой по смыслу задаче).

## Выбор метрик

Очевидно, что в данной задаче будем брать recall как целевую метрику, полнота классификаций очень важна.

Помимо recall на валидации будем смотреть на f1 и roc-auc для выбора лучшей модели.
